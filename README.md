# Nagi Works 公開説明サイトの下書き

未公開。Google / YouTube への申請に使用できる完成版ではありません。

## 確認方法

`index.html` をブラウザで開くと、ツール紹介とプライバシー説明を確認できます。
ビルドやインストールは不要です。外部スクリプト、アクセス解析、フォームはありません。

## 公開前の作業

1. `privacy.html` の「［公開用の運営者表示を入力］」を確定します。
2. 「［公開用の連絡先メールアドレスを入力］」を本人が直接置き換えます。チャットへ貼る必要はありません。公開するとページの閲覧者に見える連絡先です。
3. 実際の機能・処理先・保持期間・削除方法と説明を照合します。未実装の機能を実装済みと表現しません。開発段階の案内として公開する場合も、その状態を明示します。
4. ページの文面と公開先を本人が確認し、公開用の内容に確定します。未公開・仮欄の表記と更新日も見直します。
5. 専用リポジトリ（例：`nagiworks-info`）へ、このフォルダの公開用3ファイルだけをコピーします。既存実装リポジトリの履歴・ファイル・録画・申請情報は含めません。
6. GitHub Pages を有効にする操作は、内容を確定してから行います。公開後、2ページとリンクをブラウザで確認します。

公開用ファイルは `index.html`、`privacy.html`、`style.css` です。この README は作業用です。
`noindex` は検索エンジン向けの指示であり、閲覧制限ではありません。

## 検証の範囲

HTML の構造、文字コード、ローカルリンク、実行コードがないことを静的に検査しています。
この環境ではブラウザ表示の確認はできていません。公開前にパソコンとスマートフォン幅で表示を確認してください。
