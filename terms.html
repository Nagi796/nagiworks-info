内部ツール・競合分析は開発中

利用者は運営者本人です。一般向けのサービス提供、登録、利用者への課金は行っていません。実データによる競合分析はまだ有効になっていません。

1. 対象と目的

この利用条件は、Nagi Works が運営する内部ツール「Nagi Works Video Planning」に適用します。独自の動画企画を検討するためのツールであり、YouTube API データへのアクセスを販売するサービスではありません。

2. YouTube API Services

YouTube API Services を利用する本ツールの機能を利用することにより、利用者はYouTube 利用規約に拘束されることに同意するものとします。

予定している競合分析の用途とデータの取り扱いについて、適用される条件と必要な審査・許可を確認してから実運用を開始します。このページの掲載は、YouTube または Google による承認や推奨を意味しません。

3. プライバシー説明の確認

利用者は、機能を利用する前にプライバシー説明を確認し、そこに記載されたデータの取り扱いに同意するものとします。実運用開始前に、実装と説明の一致および利用前の確認手順を検証します。

4. 分析結果の扱い

参照した YouTube の情報と、AI による解釈・仮説・運営者の編集上の判断を区別します。動画のメタデータだけで、動画本編の内容、需要、成功要因を確認できたとは扱いません。企画に用いる事実は必要な一次資料で別途確認します。

5. 変更と問い合わせ

機能やデータの取り扱いを変更した場合は、利用条件とプライバシー説明を更新します。問い合わせ先はプライバシー説明の連絡先をご確認ください。
