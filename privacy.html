2. 取得を予定する情報と目的

YouTube API Services を利用して、企画に関係する公開動画の動画 ID、タイトル、説明、公開日時、チャンネル識別情報を取得する予定です。必要に応じて動画の長さや公開統計情報も利用します。

目的は、公開情報の整理と、運営者自身の動画企画の検討です。参照したデータと、AI を利用した解釈・仮説・編集上の判断を区別します。

初期の設計では、コメント、字幕、動画・音声ファイル、サムネイル画像を取得しません。Google アカウントへの OAuth 認可による非公開情報へのアクセスや、YouTube への書き込みは行わない設計です。

3. 処理先と保存先

Anthropic が提供する Claude Code のクラウド環境で処理し、関連する公開メタデータを Claude による整理に利用する予定です。許容されるメモや企画は Notion に、一時的な作業データはクラウドの実行環境に保存することを想定しています。

実運用前に、利用する契約・設定に基づく提供先、保持期間、モデル改善への利用設定、削除方法を確認し、この説明に反映します。現時点では、実データを使う一連の処理について、各提供者での取り扱いを検証し終えていません。

4. 保存期間・更新・削除

YouTube API データに適用される要件に従い、対象となる公開メタデータは取得から30暦日以内の更新または削除を行う設計です。対象データのコピーや、そのデータに依存する記述も、適用される要件に応じて管理します。

申請したことだけを理由に保存期間を延長することはありません。保持期間や利用条件が異なるデータを扱う場合は、必要な許可と条件を確認したうえで説明を更新します。

現在確認済みの試作は、架空データを保存した2つのファイルから参照情報を手動で除去するものです。実データの自動削除、Notion の履歴、ログ、処理事業者の保存領域やバックアップを含む管理は未実装・未検証です。実運用前に保存先ごとの対応を確定します。

5. 問い合わせ・削除の相談

対象となる動画 URL や記録、相談内容を、上記の連絡先へお知らせください。API キー、パスワードなどの認証情報は送らないでください。適用される規約・法令に従って確認・対応する手順を、運用開始前に整備します。

このツール内の情報の削除は、YouTube 上の元のコンテンツを削除するものではありません。将来 OAuth 認可を導入する場合は、認可の取り消し方法と関連データの削除方法を追加します。
