VIDEO PLANNING

Nagi Works Video Planning

Nagi Works Video Planning は、運営者本人が動画のテーマや構成を検討するための内部ツールです。

開発状況の案内

このサイトは内部ツールの説明ページです。競合分析機能は開発中で、実データによる分析はまだ有効になっていません。このサイトからツールを利用することはできません。

何をするツールか

独自の動画企画を出発点に、関連する公開動画の情報を参考にしながら、扱うテーマや説明の順序を検討します。競合調査は、キーワード選定後に必要に応じて行う補助工程です。

想定する利用者は運営者本人です。制作した動画の視聴者に、この内部ツールのアカウント作成やログインを求めるものではありません。

開発中の競合分析

  1. 企画に関係するキーワードで、YouTube の公開動画を調べます。
  2. タイトルや説明などを参考に、扱われている論点を整理します。
  3. 参照情報と運営者の判断を区別し、元の企画を見直します。

今後の機能では YouTube API Services の利用を予定しています。メタデータだけで動画本編の内容、需要、成功要因を確認できたとは扱いません。AI による解釈も、確認済みの事実と区別します。

現在の状態

架空データを使った試作と、そのデータを期限に合わせて手動で除去する動作を確認しています。実データを取得して AI で分析する競合分析機能は、まだ有効になっていません。

実運用を始める前に、必要な審査・許可の確認、保存先ごとのデータ管理の実装と検証、説明文の更新を行います。

データの取り扱い

取得を予定する情報、利用目的、処理先、保存・削除の考え方は、プライバシー説明に記載しています。

内部ツールの利用条件は、利用条件をご確認ください。

YouTube API Services を利用する機能の利用には、YouTube 利用規約が適用されます。
